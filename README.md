# แผนที่เฝ้าระวังโรคและแมลง จังหวัดเพชรบูรณ์

เว็บแอปพยากรณ์ความเสี่ยงการระบาดของโรคและแมลงศัตรูพืชรายตำบล (11 อำเภอ 117 ตำบล) ล่วงหน้า 7 วัน
สำหรับเจ้าหน้าที่และเกษตรกร ครอบคลุมพืช 17 ชนิดชุดเดียวกับแอปปฏิทินเพาะปลูกเท่าทันภูมิอากาศ
และมีชั้นข้อมูลภัยธรรมชาติ (ฝนหนัก/น้ำท่วมขัง และฝนทิ้งช่วง/แล้ง)

## ใช้งานอย่างไร
1. เลือกพืชที่ปลูก → แผนที่ระบายสีทุกตำบลตามระดับความเสี่ยงสูงสุดใน 7 วัน
2. รายการ “สัปดาห์นี้ควรเฝ้าระวัง” บอกว่าโรค/แมลงชนิดไหนเข้าเกณฑ์กี่ตำบล แตะเพื่อดูแผนที่เฉพาะชนิด
3. แตะตำบล (หรือกด “ตำบลของฉัน”) เพื่อดูพยากรณ์อากาศ ระยะพืช เหตุผลที่เข้าเกณฑ์ และวิธีจัดการ
4. แท็บ “ตามพื้นที่” แสดงเฉพาะพืชที่ปลูกในแต่ละอำเภอ เลือกอำเภอเพื่อดูรายพืชและโรค/แมลงเด่น
5. ปุ่ม “รายงานหน้าเดียว” เลือกพื้นที่ พืช และประเภทข้อมูล แล้วพิมพ์/บันทึก PDF (A4) หรือคัดลอกข้อความไปวางใน LINE
6. พืชไร่และผักระบุวันปลูกได้ ถ้าไม่ระบุจะใช้ฤดูปลูกของจังหวัดจากแผนพัฒนาการเกษตรฯ

ระดับ: ปกติ → เฝ้าระวัง (เริ่มเข้าเงื่อนไข) → แจ้งเตือน (ครบเกณฑ์) → เสี่ยงสูง (ครบเกณฑ์และเกณฑ์มีฐานข้อมูลแข็งแรง)

## โครงสร้าง
```
src/data/crops.js, alertRules.js, durianStages.js   คัดลอกจากแอปปฏิทินเพาะปลูก v18 (ไม่แก้ไข)
src/data/pestCalendars.js  ปฏิทินศัตรูพืชจากไฟล์ Excel (มะขามหวาน อะโวคาโด มะคาเดเมีย อ้อย ถั่วเขียว) ใช้แทนชุดเดิมของพืชเหล่านี้
src/data/growthRules.js    เกณฑ์สภาพแวดล้อมต่อการเจริญเติบโต/ออกดอก/คุณภาพผลผลิต (ถั่วเขียว อ้อย มะขามหวาน อะโวคาโด มะคาเดเมีย)
src/data/plantingCalendar.js  น้ำหนักการปลูกรายเดือนของข้าว ข้าวโพด มันสำปะหลัง ถั่วเขียว อ้อย (จังหวัด/อำเภอ) จากทะเบียนเกษตรกร ใช้คิดระยะพืช (ไม่แสดงในเว็บ)
src/data/tambonSoil.json   ข้อมูลกลุ่มชุดดินรายตำบล (กรมพัฒนาที่ดิน) สร้างด้วย scripts/build_soil.py
src/lib/soil.js, soilCore.js  การปรับระดับความเสี่ยงตามดิน และคำแนะนำจากดิน
src/data/rules.js          รวมเกณฑ์ทั้งหมดที่ใช้คำนวณ
src/data/districtCrops.js  พืชที่ปลูกในแต่ละอำเภอ สำหรับมุมมอง "ตามพื้นที่" (แก้ได้ที่ไฟล์นี้)
src/data/seasons.js        ฤดูปลูก/พื้นที่ปลูกจากแผนพัฒนาการเกษตรและสหกรณ์ จ.เพชรบูรณ์ 2571–2575
src/data/tambons.json      ขอบเขต 117 ตำบล (OpenGISData-Thailand, CC BY 4.0) + จุดคำนวณอากาศ
src/lib/wxparse.js         เรียกและแปลงข้อมูล Open-Meteo (ใช้ทั้งเว็บและสคริปต์)
src/lib/stages.js          หาระยะพืช (ไม้ผลตามเดือน / พืชไร่ตามฤดูปลูกหรือวันปลูก)
src/lib/risk.js            ประเมินเกณฑ์ทุกวันในสัปดาห์ แล้วสรุปเป็นระดับรายตำบล
src/lib/hazards.js         ฝนหนัก/น้ำท่วมขัง และฝนทิ้งช่วง/แล้ง
scripts/fetch-weather.mjs  ดึงอากาศ 117 ตำบลรวดเดียวเป็น public/data/weather.json
scripts/line-broadcast.mjs (ไม่บังคับ) ส่งสรุปรายสัปดาห์เข้า LINE OA
```

## ติดตั้งและทดสอบในเครื่อง
```
npm install
npm run dev        # เปิด http://localhost:5173
npm test           # ทดสอบเครื่องคำนวณด้วยข้อมูลจำลอง
```

## นำขึ้นเซิร์ฟเวอร์ฟรี
**ทางเลือก A: GitHub Pages + GitHub Actions (แนะนำ)**
1. สร้าง repository แล้ว push โค้ดนี้ขึ้นสาขา `main`
2. Settings → Pages → Build and deployment → Source: เลือก **GitHub Actions** (ต้องทำก่อนรัน workflow ครั้งแรก ไม่อย่างนั้นขั้น deploy จะขึ้น 404) ถ้าบัญชีเป็นแบบฟรี repository ต้องเป็น Public
3. Workflow `daily-weather` จะดึงอากาศ 117 ตำบลทุกวัน 05:10 น. แล้ว deploy ให้อัตโนมัติ
   ผู้ใช้ทุกคนโหลดไฟล์อากาศไฟล์เดียว จึงไม่ติดโควตา API แม้มีผู้ใช้มาก

**ทางเลือก B: Vercel / Netlify / Cloudflare Pages**
นำเข้า repository แล้วตั้ง Build command `npm run build` และ Output `dist`
แบบนี้เบราว์เซอร์ของผู้ใช้จะเรียก Open-Meteo เอง (แคชไว้ 3 ชั่วโมง) ใช้ได้ทันทีโดยไม่ต้องตั้งค่าเพิ่ม

## แจ้งเตือนผ่าน LINE (ไม่บังคับ)
1. สร้าง LINE Official Account และเปิด Messaging API ที่ LINE Developers
2. ใน GitHub: Settings → Secrets and variables → Actions
   - Secret `LINE_CHANNEL_ACCESS_TOKEN` = Channel access token
   - Variable `SITE_URL` = ลิงก์เว็บไซต์
3. ทุกวันจันทร์ระบบจะ broadcast สรุปโรค/แมลงเด่นของแต่ละพืช และตำบลที่เสี่ยงน้ำขัง
   ทดลองข้อความก่อนได้ด้วย `node scripts/line-broadcast.mjs public/data/weather.json --dry-run`

## ระยะพืชไร่และข้าว
ใช้ข้อมูลช่วงเวลาการเพาะปลูกของจังหวัด (จำแนกตามวันปลูก รายอำเภอ) ปี 2567–2569
แต่ละปีแปลงเป็นสัดส่วนเนื้อที่ปลูกรายเดือน แล้วเฉลี่ยทุกปีโดยให้น้ำหนักเท่ากัน ข้าว = นาปี + นาปรัง ถ่วงตามเนื้อที่
ระบบคำนวณสัดส่วนแปลงในแต่ละระยะ ณ วันที่ประเมิน แยกรายอำเภอ (อำเภอที่ปลูกน้อยกว่า 200 ไร่/ปี ใช้ค่าจังหวัด)
เกณฑ์ที่ใช้กับระยะที่มีแปลงน้อยกว่า 15% เตือนได้สูงสุดแค่ “เฝ้าระวัง”
อัปเดตข้อมูลปีใหม่: `python3 scripts/parse_planting.py <ไฟล์.xlsx> raw.json && python3 scripts/build_planting.py raw.json src/data/plantingCalendar.js`

## ข้อมูลดิน
ใช้ shapefile กลุ่มชุดดินจังหวัดเพชรบูรณ์ของกรมพัฒนาที่ดิน ซ้อนทับกับขอบเขตตำบลแล้วคิดสัดส่วนตามพื้นที่
- ตำบลที่เป็นที่ลุ่ม/ดินเหนียว → โรครากเน่า โคนเน่า เหี่ยวเน่าแดง และภัยน้ำขัง ปรับระดับขึ้นหนึ่งขั้น
- ตำบลดินทราย → ปลวก หนอนด้วงขาว ปรับระดับขึ้นหนึ่งขั้น
- ตำบลดินทราย/ดินตื้น → เกณฑ์ขาดน้ำและฝนทิ้งช่วงเข้มขึ้น (7/12/17 วันแทน 10/15/20 วัน)
- ดินกรด ดินด่าง ลาดชัน ความอุดมสมบูรณ์ต่ำ → แสดงคำแนะนำในหน้าตำบล
ถ้าได้ shapefile ชุดใหม่ ให้รัน `python3 scripts/build_soil.py <ไฟล์ .shp ไม่ใส่นามสกุล> src/data/tambons.json src/data/tambonSoil.json` (ต้องติดตั้ง pyshp, pyproj, shapely)

## ข้อจำกัด
- ข้อมูลอากาศเป็นค่าจากแบบจำลอง (ความละเอียดประมาณ 10–25 กม.) ณ จุดกึ่งกลางตำบล ไม่ใช่สถานีวัดในแปลง
- “ชั่วโมงใบเปียก” ประมาณจากชั่วโมงที่ความชื้นสัมพัทธ์ ≥ 90%
- ไม่มีข้อมูลพื้นที่ปลูกรายตำบล ระบบจึงแสดงความเสี่ยงทุกตำบล ผู้ใช้เลือกดูเฉพาะพืชที่ตนปลูก
- ต.หล่มสัก อ.หล่มสัก ไม่มีในชุดข้อมูลต้นทาง (ถูกรวมกับ ต.ตาลเดี่ยว) จึงใช้ขอบเขตโดยประมาณรัศมีราว 1.3 กม. รอบตัวเมือง
- ผลประเมินคือสัญญาณให้ออกสำรวจแปลง ใช้สารเคมีเมื่อสำรวจพบถึงเกณฑ์เศรษฐกิจเท่านั้น
